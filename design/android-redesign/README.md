# Settlr for Android: redesign mockups

The Android redesign in the **Tally** design language: violet ink on cool paper, Bricolage Grotesque numerals and Manrope text.

- `canvas.json`: the board layout, with the rows and notes.
- `*.dc.html`: one file per screen (412×915). `Main`, `System`, `Components` and `Motion` are the foundation boards.
- `settlr.css`: the shared tokens, primitives, icons and motion.

These are Design canvas source files. They load a `support.js` runtime that is served by the canvas, not kept here. Open the canvas to view and click through them.

Data in the mockups is sample data. Synced with the web features on `main` as of 26 Nov 2026.
